# Agent Governance

Canonical agent operating rules live in [`docs/AGENTS_SPEC.md`](docs/AGENTS_SPEC.md).

Standing directives:

- **Commander Directive — Rapid Industry Research Before Action**: before
  answering or executing a Commander command, run a concise research pass on
  current industry practice, present bullet-point findings, then respond in the
  required structure (findings → repo impact → decision → plan → verification).
  See `docs/AGENTS_SPEC.md` for the full protocol.
- Skill maintenance rules live in [`docs/SKILLS_SPEC.md`](docs/SKILLS_SPEC.md).
- Substantial research is filed under `docs/research/YYYY-MM-DD-<topic>.md`.
