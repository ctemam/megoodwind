# Skill Governance

Canonical skill acquisition and maintenance rules live in
[`docs/SKILLS_SPEC.md`](docs/SKILLS_SPEC.md).

Standing directives:

- **Continuous Research and Skill Maintenance**: source quality order
  (standards → official docs → primary research → reputable references →
  labeled secondary), mandatory labeling of findings
  ([verified]/[repo evidence]/[assumption]/[unknown]), and folding reusable
  lessons back into the skill matrices. See `docs/SKILLS_SPEC.md`.
- Agent operating rules live in [`docs/AGENTS_SPEC.md`](docs/AGENTS_SPEC.md).
